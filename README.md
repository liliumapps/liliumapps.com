# liliumapps.com

The Lilium Apps studio website: the app list, about, and contact. Each app has
its own website and repository (for example lumen.liliumapps.com); this site
links to them.

```bash
npm install
npm run develop   # http://localhost:8000
npm run build     # static site in public/
```

Pushing `main` deploys to GitHub Pages. The app list lives in
`src/data/projects.js`. Icons in `static/` are generated by the brand kit
(`branding/`, `npm run build`); don't edit them by hand. App banners in
`static/apps/` are each app's Play feature graphic from the brand kit's listing
renderer (`branding/listing`), at twice its size, as WebP; VLC Remote's shows its
controls screen instead of the player. Set per app with `banner` in `projects.js`.
